# 📊 Retail Sales Dashboard – Power BI

## 📌 Project Overview

This project is a Retail Sales Dashboard created as part of a hands-on Power BI webinar learning project.

The dashboard provides an interactive view of retail sales performance and helps analyze sales, profit, customers, products, regions and payment modes.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- Data Cleaning
- Data Transformation
- Data Modeling
- Data Visualization

## 🔄 Data Preparation

The raw retail sales data was loaded into Power BI and transformed using Power Query.

Key transformation steps included:

- Handling null/missing values
- Splitting columns
- Removing unwanted columns
- Cleaning and preparing the dataset
- Creating structured tables

## 🔗 Data Modeling

After data transformation, relationships were created between the required tables to prepare the data model for analysis and visualization.

## 📊 Dashboard Features

- Gross Sales
- Net Sales
- Total Profit
- Total Customers
- Total Orders
- Sales by Region
- Profit by Category
- Sales by Product
- Store Type Analysis
- Payment Mode Analysis
